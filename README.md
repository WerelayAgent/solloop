# SolLoop ($SOLLOOP)

> **Call it. Prove it. Get paid on Solana.**

SolLoop is the premier on-chain token launchpad and SocialFi network built natively for the **Solana** ecosystem. Every token call is verified on-chain, every receipt is transparently auditable, and Looper callers earn instant revenue share from every trade.

---

## 🌟 Fitur Utama

- **Solana Native Speed & Low Fees**: Dioptimalkan untuk kecepatan transaksi instan dan gas fee minimal di blockchain Solana.
- **Raydium & Meteora Liquidity Lock**: Setiap peluncuran koin yang mencapai target bonding curve langsung lulus (*graduate*) ke pool Raydium CPMM / Meteora DLMM dengan likuiditas yang terkunci permanen (LP burn).
- **Proof-of-Call SocialFi Engine**: Callers/KOL membagikan rekomendasi token secara terverifikasi on-chain dan menerima bagi hasil volume trading otomatis.
- **Multi-Wallet Support**: Integrasi mulus dengan wallet Solana terpopuler: **Phantom**, **Solflare**, dan **Backpack**.
- **Interactive Multi-Page Hub**:
  - `/` (Beranda & Hero Showcase)
  - `/explore` (Katalog Token & Filter Interaktif)
  - `/degen` (Terminal Fast-Trading & Realtime Orderflow)
  - `/loopers` (Leaderboard Callers & Sistem Bagi Hasil)
  - `/create` (Portal Deploy Token Solana)
  - `/docs` (Dokumentasi Protokol & Parameter Bonding Curve)
  - `/analytics` (Dashboard Metrik On-Chain Solana)

## 🚀 Jalankan Secara Lokal

```bash
# Menggunakan npx serve
npx serve .

# Atau menggunakan Python HTTP Server
python -m http.server 8080
```

Buka `http://localhost:8080` di browser.

## 🌐 Deployment (Vercel)
